# Ontological Foundation

## Wrong Model ❌

```
AIContent = Slop
HumanContent = NotSlop
```

## Correct Model ✅

```
ContentItem
  ├── hasGenerationMode        (human, ai_assisted, synthetic)
  ├── hasHumanOversightLevel   (full, partial, minimal, none)
  ├── hasQualityProfile        (density, coherence, originality, factuality)
  ├── hasDistributionPattern   (organic, seo_optimized, engagement_farmed, adversarial)
  ├── hasIntent                (inform, monetize, manipulate, fill)
  ├── hasProvenanceStatus      (verified, unverified, fake_author, spoofed)
  ├── hasRiskProfile           (clean, ai_assisted, suspicious, slop, malicious)
  └── hasSlopScore             (0.0 – 1.0)
```

**AI Slop as a derived class / score-based classification:**

```
AI_Slop ≈ ContentItem
    AND synthetic_or_ai_assisted
    AND low_quality_or_low_substance
    AND low_effort_or_low_verification
    AND mass_produced_or_engagement_optimized_or_deceptively_distributed
```

## Top-Level Classes

| Class | Meaning |
|--------|-----------|
| **ContentItem** | Individual content: text, image, video, audio, code, document, listing, comment |
| **SyntheticContent** | Content wholly or partially generated by generative AI |
| **AI_AssistedContent** | Human content produced with AI assistance (research, drafting, editing) |
| **AI_SlopCandidate** | Content suspected of being slop |
| **ConfirmedAI_Slop** | Content with sufficient evidence for a slop classification |
| **LowQualityHumanContent** | Poor human content, but not necessarily AI slop |
| **SpamContent** | Unwanted or manipulative content, regardless of AI involvement |
| **MisinformationContent** | Content containing false or misleading claims |
| **SyntheticMedia** | Image, video, audio or multimodal synthetic content |
| **SlopProducer** | Account, bot, content farm, SEO cluster, channel, uploader |
| **DistributionChannel** | Platform, search engine, feed, marketplace, RAG corpus |
| **DetectionEvidence** | Indicators: metadata, artifacts, repetition patterns, hallucinations |
| **MitigationAction** | Labeling, demonetizing, downranking, excluding, human review |

## Taxonomy by Medium

### Text Slop
**Examples:** Blog articles, LinkedIn posts, SEO pages, product descriptions

| Slop Marker | Description |
|-------------|-------------|
| Generic structure | The same recurring layout: intro → list → conclusion |
| Few sources | No references or only generic ones |
| Filler phrases | "In today's fast-paced world", "it's important to note" |
| False facts | Hallucinations, fabricated statistics |
| Em-Dash Overuse | Excessive use of "—" |
| Low Density | unique_words / total_words < 0.40 |

### Image Slop
**Examples:** Fake historical images, viral animals, product images

| Slop Marker | Description |
|-------------|-------------|
| Anatomical errors | Extra limbs, fused fingers |
| Surreal realism | Too perfect, uncanny valley |
| Context break | Elements that do not fit together |
| Bad Text Rendering | Gibberish in the image |
| Glossy Textures | Unnaturally smooth surfaces |

### Video Slop
**Examples:** YouTube kids' content, AI news, fake documentaries

| Slop Marker | Description |
|-------------|-------------|
| Repetitive scenes | Same sequences repeated |
| AI voiceover | Synthetic voice without emotional variation |
| No real dramaturgy | Sequence without narrative arc |
| Frame Flicker | Inconsistencies between frames |
| Lip-Sync Mismatch | Audio-visual desynchronization |

### Audio Slop
**Examples:** AI music, voice clones, fake podcasts

| Slop Marker | Description |
|-------------|-------------|
| Mass uploads | Hundreds of tracks at once |
| Generic composition | Formulaic song structure |
| Identity misuse | Fake artist profiles |

### Academic Slop ⚠️ Particularly dangerous
**Examples:** Papers, preprints, review articles

| Slop Marker | Description |
|-------------|-------------|
| Fake Citations | Hallucinated references |
| Superficial literature reviews | Rehash without analysis |
| Template structure | The same recurring layout |
| Unedited prompt text | Direct LLM outputs |

**arXiv tightened its rules in 2026** against obviously unvalidated LLM content such as hallucinated references or unedited prompt text.

**NeurIPS-2025-Fabricated-Citations:** AI-hallucinated citations exploit multiple plausibility heuristics simultaneously — making them especially hard to detect.

### Code Slop
**Examples:** AI-generated PRs, issues, docs

| Slop Marker | Description |
|-------------|-------------|
| Does not compile | Syntactic errors |
| Wrong APIs | Hallucinated package names (19.7% rate) |
| Review burden | Massive numbers of trivial PRs |
| Copy-paste patterns | Uniform code style |
| Hardcoded Secrets | API keys in the code |

### Legal Slop ⚠️ Particularly dangerous
**Examples:** AI-generated legal briefs

| Slop Marker | Description |
|-------------|-------------|
| Invented precedents | Hallucinated court rulings |
| False norms | Non-existent statutory references |
| Unvalidated citations | Sources that do not exist |

### Work Slop
**Examples:** Internal reports, presentations, memos

| Slop Marker | Description |
|-------------|-------------|
| Looks professional | Superficially convincing |
| Saves the sender's time | Quickly produced |
| Costs the recipient's time | Must be read/evaluated |

> "Especially the academic and professional variants are dangerous because they don't always look 'cheap'."

## Taxonomy by Intent

| Intent Class | Description | Risk Level |
|---------------|-------------|---------------|
| **AttentionFarming** | Reach, likes, watch time | 🟠 High |
| **AdRevenueFarming** | Monetization via ads | 🟠 High |
| **RoyaltyDilution** | Streaming royalties via mass-produced music | 🟠 High |
| **SearchManipulation** | SEO, GEO, ranking manipulation | 🔴 Critical |
| **RecommendationPoisoning** | Placing content so that AI answer systems prefer it | 🔴 Critical |
| **AffiliateFunnel** | AI content as a traffic funnel | 🟡 Medium |
| **CredentialInflation** | Papers, citations, profiles used to boost reputation | 🟠 High |
| **Disinformation** | Intentionally misleading synthetic content | ⚫ Malicious |
| **CarelessSpeech** | Not necessarily malicious, but unchecked, superficial, misleading | 🟡 Medium |
| **Impersonation** | Voice, style, name, brand or person being imitated | 🔴 Critical |
| **PlaceholderPublishing** | Content is published even though it is only a draft / filler material | 🟡 Medium |

**Google** has by now extended its spam rules to cover **manipulation of generative search systems** — affecting attempts to influence AI Overviews or AI Mode.

## Class Hierarchy (Formal)

```
ContentItem
├── hasGenerationMode → GenerationMode
│   ├── Human
│   ├── AI_Assisted
│   └── Synthetic
├── hasHumanOversightLevel → OversightLevel
│   ├── Full (thorough research + editing)
│   ├── Partial (review but no deep check)
│   ├── Minimal (cursory glance)
│   └── None (published directly)
├── hasQualityProfile → QualityProfile
│   ├── hasDensity → float (0-1)
│   ├── hasCoherence → float (0-1)
│   ├── hasOriginality → float (0-1)
│   ├── hasFactuality → float (0-1)
│   └── hasUtility → float (0-1)
├── hasDistributionPattern → DistributionPattern
│   ├── Organic
│   ├── SEOOptimized
│   ├── EngagementFarmed
│   ├── Adversarial
│   └── PlatformAmplified
├── hasIntent → Intent
│   ├── Inform
│   ├── Monetize
│   ├── Manipulate
│   └── Fill
├── hasProvenanceStatus → ProvenanceStatus
│   ├── Verified (clear authorship, sources)
│   ├── Unverified (no clear origin)
│   ├── FakeAuthor (AI headshot, no history)
│   └── Spoofed (identity falsified)
├── hasRiskProfile → RiskLevel
│   ├── Clean
│   ├── AI_Assisted
│   ├── Suspicious
│   ├── Slop
│   └── Malicious
└── hasSlopScore → float (0.0-1.0)

AI_SlopCandidate ≡ ContentItem ∧ (synthetic ∨ ai_assisted) ∧ slopScore > threshold
ConfirmedAI_Slop ≡ AI_SlopCandidate ∧ detectionEvidence.count ≥ 2
```

## Overlaps Between Classes

```
              Slop
             /    \
            /      \
     Synthetic    LowQuality
        |    \      /    |
        |     \    /     |
        |   AI_Slop     |
        |                |
   Spam ──────── Misinformation
        \                /
         \              /
          CarelessSpeech
```

**Slop can be spam, but not all slop is spam.**
**Slop can be misinformation, but not all slop is intentional.**
**LowQualityHumanContent is worthless but not necessarily slop.**
