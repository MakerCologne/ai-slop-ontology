# AI Slop Ontology

A machine-readable ontology for classifying, detecting, and reasoning about AI-generated slop content. Designed for agent consumption — load the ontology, classify content, detect signals, recommend countermeasures.

## What is AI Slop?

AI slop is low-quality, formulaic, or repetitive content generated by AI systems at scale. The term was Merriam-Webster's Word of the Year 2025. It encompasses text, images, video, audio, and code that appears competent on the surface but lacks substance, originality, or informational value.

## Quick Start for Agents

### Load the Ontology

```python
import json

with open("ontology.json") as f:
    ontology = json.load(f)

# Access slop types
text_slop_types = ontology["slopTypes"]["TEXT_SLOP"]
# → GenericSlop, PseudoInsightSlop, FakeAuthoritySlop, WikipediaRehash, WellnessSlop

# Access detection signals
text_signals = ontology["signals"]["text"]
# → BuzzwordOveruse, PunctuationAnomaly, GenericTransition, LowPerplexity, UniformSentenceLength
```

### Classify Content

Agents should follow this workflow:

1. **Identify modality** — text, image, video, audio, code
2. **Check for signals** — look for indicators from the `signals` section
3. **Run detection methods** — modality-specific checks
4. **Classify slop type(s)** — from `slopTypes`
5. **Measure dimensions** — from `dimensions` (density, repetition, verbosity, etc.)
6. **Assess normative framing** — if harm evaluation needed
7. **Recommend countermeasures**

### Output Format

```json
{
  "modality": "text",
  "slopTypes": ["GenericSlop", "PseudoInsightSlop"],
  "signalsDetected": [
    {"signal": "BuzzwordOveruse", "confidence": 0.9, "evidence": "Found: delve, tapestry, leverage"}
  ],
  "dimensions": {
    "Density": {"value": 0.32, "isSlop": true},
    "Repetition": {"value": 0.28, "isSlop": true}
  },
  "overallSlopScore": 0.78,
  "severity": "high",
  "countermeasures": ["PromptEngineering", "QualityGates"]
}
```

## Ontology Architecture

### Core Classes

| Class | Description |
|-------|-------------|
| **SlopInstance** | A concrete slop observation |
| **SlopType** | Hierarchical classification (text/image/video/audio/code/domain) |
| **SlopDimension** | Measurable quality axes (Density, Repetition, Verbosity, etc.) |
| **SlopSignal** | Observable indicators (BuzzwordOveruse, ExtraLimbs, etc.) |
| **NormativeFraming** | Why it's harmful (Epistemic Pollution, Consumer Fraud, etc.) |
| **DetectionMethod** | Techniques for identification |
| **Countermeasure** | Prevention and remediation actions |

### Slop Types by Modality

**Text:** Generic, Pseudo-Insight, Fake Authority, Wikipedia Rehash, Wellness, SEO, Academic, Political, Review  
**Image:** Surreal Engagement Bait, Fake Photograph, Fake Product  
**Video:** AI-Generated Video (children's content, educational misinformation)  
**Audio:** Fake Artist Music  
**Code:** Hallucinated Packages, Uniform Code  

### Measurable Dimensions (Shaib et al. 2025)

- **Information Utility:** Density, Relevance
- **Information Quality:** Factuality, Bias
- **Style Quality:** Repetition, Templatedness, Coherence, Fluency, Verbosity, Word Complexity, Tone
